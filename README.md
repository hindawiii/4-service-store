💳 حلول الدفع في السودان (الأهم)

المشكلة:

PayPal: محظور في السودان ❌

Stripe: يحتاج شركة خارجية ❌

Visa/Mastercard: نادرة الاستخدام ❌

الحلول المتاحة:

Table

الطريقة	التفاصيل	التكلفة	الصعوبة

1. بنكك (Bankak)	محفظة إلكترونية سودانية شائعة	عمولة منخفضة	سهلة — العميل يحوّل لك

2. فوري (Fawry)	إذا كانت متاحة	متوسطة	متوسطة

3. تحويل بنكي مباشر	حسابك في بنك سوداني	صفر	سهلة جداً

4. كاش/واتساب	العميل يتواصل ويدفع كاش	صفر	يدوية

5. العملات المشفرة (USDT)	شائعة جداً في السودان	شبكة BEP-20 رخيصة	تحتاج تعلم بسيط

الآلية المقترحة (الأسهل والأكثر واقعية):

plain

1. العميل يضغط "اطلب الخدمة"

2. يُنقل لصفحة "إتمام الطلب"

3. يظهر رقم بنكك / رقم الحساب البنكي / رقم USDT

4. العميل يُرسل إثبات الدفع (صورة) عبر واتساب أو نموذج رفع ملف

5. أنت تُؤكد الدفع يدوياً من لوحة التحكم

6. يتغير حالة الطلب إلى "مكتمل"

7. تُرسل الخدمة للعميل عبر المنصة أو واتساب

المرحلة 2: قاعدة البيانات (مطلوبة)

تحتاج جدولاً جديداً في قاعدة بيانات Lovable (Supabase):

sql

-- جدول الخدمات

services:

  - id (UUID)

  - name (عنوان الخدمة)

  - description (الوصف)

  - price (السعر)

  - category (التصنيف: software, ai, support, course)

  - image (صورة)

  - is_active (متاح/غير متاح)



-- جدول الطلبات

orders:

  - id (UUID)

  - user_id (معرف المستخدم)

  - service_id (معرف الخدمة)

  - status (pending, confirmed, completed, cancelled)

  - payment_method (bankak, cash, usdt)

  - payment_proof (رابط صورة إثبات الدفع)

  - created_at (تاريخ الطلب)

  - notes (ملاحظات)
